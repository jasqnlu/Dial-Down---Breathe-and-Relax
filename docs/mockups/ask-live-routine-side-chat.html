How it behaves
  • Count wins. "3 exercises" always gives 3 rows. An L + R pair counts as one.
  • Count + time splits the time evenly: 3 for 3 min is 1:00 each.
  • Time only keeps adding until it fills the time, then trims the last one to land exactly.
  • New asks add to the routine. "start over" clears it.
  • Drag the panel header right to shrink it to the pill. Drag it up to go full screen.
  • The chips under each reply show what the on-device model understood.
  • Customize (sliders button in the tray) opens the app's Customize screen. Hold a card to drag it into a new order, use − / + to change times, tap × twice to remove. Add takes you back to the chat. Every change shows up in the tray right away.
